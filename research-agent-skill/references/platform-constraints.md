# Social Media Platform Constraints

## Twitter/X

| Property | Constraint |
|----------|-----------|
| Character limit | 280 per tweet |
| Thread | Use 1/N, 2/N format |
| Links | Shortened by t.co (~23 chars) |
| Images | Up to 4, auto-displayed |
| Hashtags | 3-5 max, count toward limit |
| Tone | Smart-casual academic |

**Best practices for research:**
- Lead with the most surprising insight (hook-first)
- If threading: tweet 1 is the hook, tweet 2 is the finding, tweet 3 is the link
- Use line breaks for readability
- Avoid jargon — translate to accessible language

## LinkedIn

| Property | Constraint |
|----------|-----------|
| Character limit | 3,000 |
| Format | Supports basic formatting in app |
| Links | Full URL display |
| Hashtags | 5-8 professional tags |
| Tone | Professional, thought-leadership |

**Best practices for research:**
- Start with a problem statement or provocative question
- Structure: problem → approach → key finding → implications
- 3-4 paragraphs, 200-400 words
- Include both paper link and GitHub link
- End with a call to discussion

## Facebook

| Property | Constraint |
|----------|-----------|
| Character limit | 63,206 (but engagement drops after ~250) |
| Format | **PLAIN TEXT ONLY** — no markdown rendering |
| Links | Auto-preview with OG image |
| Tone | Accessible, science-curious audience |

**CRITICAL formatting rules:**
- NO `**bold**` — rendered as literal asterisks
- NO `*italic*` — rendered as literal asterisks
- NO `# headers` — rendered as literal hash
- NO `- ` bullets — rendered as literal dash
- USE emojis for visual structure
- USE line breaks (blank lines) to separate sections
- USE ALL CAPS sparingly for emphasis
- USE em dashes (—) and smart quotes for polish
- USE Unicode section dividers if needed

**Structure:**
Hook → Problem → Insight → Why it matters → Link → Hashtags (own line at end)

## Bluesky

| Property | Constraint |
|----------|-----------|
| Character limit | 300 |
| Format | Plain text, link cards |
| Links | Auto-preview |
| Hashtags | 2-3 max |
| Tone | Community-oriented, curious |

**Best practices for research:**
- One key insight per post
- Concise and punchy
- Link to paper for details
- Engage the decentralized science community

## Universal Rules

1. **Accuracy**: Every claim must reflect the paper's actual content
2. **No hyperbole**: Don't overstate findings or implications
3. **Differentiation**: Each platform post must be genuinely different, not just shorter/longer versions
4. **Links**: Always include the Vercel deployment URL for the specific paper page
5. **Attribution**: Credit the collaboration (`$RESEARCH_COLLABORATION` / `$RESEARCH_INSTITUTION`)
