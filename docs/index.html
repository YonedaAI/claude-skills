Install the marketplace

One-time setup inside Claude Code. After this, every plugin in the marketplace is one /plugin install away.

/plugin marketplace add YonedaAI/claude-skills

Then install any plugin from the list below.

About

claude-skills is a personal collection of Claude Code plugins extracted from real production work — research papers, shipped macOS apps, automated pipelines. Each plugin captures the hard-won gotchas of an end-to-end workflow so the next run takes hours, not weeks.

The repository is open-source under the MIT license. Pull requests welcome — see the individual plugin pages for source links and component layout.
